# Course material

The lecture script and exercise sheets belong to the course (TU Chemnitz, Automatic Control Group, Dr. Adrian Redder) and are **not published in this repository**.

To keep them alongside the notes, put your own copies here:

```
course-material/
├── Lecture-Script_OptBasedControl.pdf
└── Exercise-01_Sheet.pdf
```

`.gitignore` excludes `course-material/*.pdf`, so they will never be pushed by accident.
